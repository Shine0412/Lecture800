# 使用说明

## 运行要求

- Windows 10／11 与 Microsoft Edge WebView2。
- Windows 微信，以及本人已登录的目标小程序。
- `Lecture800.exe` 位于当前用户可写目录。
- 每日任务执行期间保持 EXE 运行、电脑不睡眠、网络可用且会话有效。

## 首次配置

1. 在微信中进入“科大微门户”的研究生学术讲座平台，打开目标页面。
2. 启动 EXE，从断连提示、设置页或使用说明页打开“配置本机会话”。
3. 阅读捕获范围与清理说明，勾选明确授权，然后点击“开始本机配置”。
4. 等第 3 步“等待微信请求”高亮后，从“科大微门户 → 应用 → 研究生学术讲座”重新进入平台；也可切换一次“我的”触发只读请求。通常几秒即可完成，最迟需在 10 分钟有效窗口内操作。
5. 后续“识别登录会话 → 只读接口验证 → 清理并完成”自动进行，无需继续操作微信。
6. 看到“连接验证通过”和实际读取数量后关闭向导。临时证书与捕获进程会自动清理。

配置只针对 `WeChatAppEx.exe` 和目标学校域名，不修改系统全局代理，不保存请求正文，也不在界面显示 Cookie／Token。向导显示六个阶段、已进行时间、剩余时间和当前提示，并明确区分“尚未看到请求”“已收到请求但未识别会话”和“验证失败”；诊断只包含接口路径及字段名称，不包含密钥。若提示权限不足，关闭 EXE 后手动选择“以管理员身份运行”再试；软件不会静默提权。

若等待期间一直没有看到目标请求，点击“停止并清理”，完全关闭所有微信小程序窗口后重新配置；仍无响应时，退出并重新打开微信后再试。不要只在原页面反复下拉刷新，旧连接可能不会产生新的可捕获请求。

取消、超时或验证失败都会执行清理。重新配置验证失败时，软件会尝试恢复原会话。

## 手动与即时报名

- 在可报名讲座的卡片或详情页点击“报名／手动报名”，确认后只提交该讲座。
- 在首页点击“立即开始自动抢课”，确认后会立即按当前地点规则并发提交全部候选，不需要等到 12:00。
- 即时抢课不会改变“每日自动报名”开关。结果窗口分别显示已提交、已核验和逐场状态；未核验到不记成功，也不自动重发。

## 每日自动报名

- 11:58：检查会话、接口和符合规则的候选课程。
- 12:00：重新读取目录，并发提交所有候选课程。
- 提交后：统一查询“我的报名”，逐场核验结果；未核验到不记成功，也不自动重发。

地点可分别选择一号院、二号院、三号院、南京校区、武汉校区和其他地点。全部取消选择表示不提交任何课程。学校服务器、名额、网络和会话状态均可能影响结果，不能保证全部抢到。

## 我的信息与退课

讲座目录和个人信息使用独立接口请求，可同时读取，不需要切换小程序页面。退课必须二次确认；只有重新查询并确认报名记录消失后，才显示成功。

## 换电脑

单个 EXE 可复制启动，但不能复制有效登录状态。DPAPI 会话绑定原电脑和 Windows 用户，因此新电脑必须重新运行内置配置向导。不要上传或复制 `session.dpapi` 作为迁移手段。
